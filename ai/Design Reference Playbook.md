# Design Reference Playbook
Version: 1.0

Purpose

This document teaches visual judgment.

It is not a style guide.

It is not a design system.

It is a collection of design philosophies that should influence every UI decision.

Never copy another product.

Understand why it works.

Then apply the principle.

---

# General Principle

Borrow principles.

Never copy layouts.

Never copy colors.

Never copy branding.

Never copy interactions.

Every implementation should feel original while following proven design thinking.

# Visual Principles

Every page should have

One visual hero

One primary message

One dominant action

Never compete for attention.

---

# Whitespace

Whitespace creates hierarchy.

Whitespace creates breathing room.

Whitespace is intentional.

Never fill whitespace with

Shapes

Gradients

Decorative icons

Background objects

---

# Typography

Typography should communicate

Importance

Grouping

Relationships

Avoid relying on

Colors

Shadows

Animations

for hierarchy.

---

# Color

Color communicates meaning.

Not decoration.

Every color should represent

Action

Status

Selection

Alert

Feedback

Never use color simply because space feels empty.

---

# Screenshots

Enterprise buyers trust products.

Not illustrations.

Product screenshots should dominate marketing pages.

Use

Real UI

Real workflows

Real modules

Avoid

Concept art

Fake dashboards

Abstract graphics

---

# Motion

Motion should explain interaction.

Not attract attention.

Allowed

Hover

Expand

Collapse

Transition

Focus

Loading

Avoid

Floating

Bouncing

Looping

Decorative movement

---

# Cards

Cards group information.

Cards are not decoration.

Every card must answer

Why does this exist?

If no answer exists,

remove it.

---

# Enterprise Trust Signals

---

# Design Smells

Immediately question any interface containing

Glassmorphism

Neon gradients

Gradient text

Oversized border radius

Floating blobs

Decorative charts

Animated backgrounds

Marketing illustrations replacing product

Centered everything

Repeating identical cards

Random icon circles

Huge shadows

If present,

remove them.

---

# AI Design Questions

Before designing ask

What increases trust?

What reduces noise?

What improves scanning?

What creates hierarchy?

What simplifies understanding?

What makes the product feel mature?

---

# Design Quality Scale

Poor

Looks generated.

Average

Looks like a template.

Good

Looks professionally designed.

Excellent

Feels invisible.

Users notice the product,

not the interface.

---

# Final Standard

The product should feel like software built by an experienced enterprise company over many years.

It should never feel like a landing page generated in one prompt.

The user should think

"This company understands my work."

not

"This website looks modern."
