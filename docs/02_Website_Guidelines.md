# FeeCollect.io – Marketing Website Guidelines

## Homepage Objectives & Structure
The website is a sales experience designed to answer customer questions sequentially.

### Mandatory 12-Section Homepage Sequence
1. **Navigation:** Fixed header with logo, minimal navigation links, and primary Brand Yellow CTA.
2. **Hero Section:** 58/42 layout split.
   - **Left (58%):** Headline ("One Platform. Every Institution."), Subheading, Primary CTA.
   - **Right (42%):** Central dashboard preview, floating module cards, connected ecosystem motif.
3. **Problem Statement:** Highlights the contrast between fragmented legacy ERPs and a unified OS.
4. **Connected Platform:** Interactive/visual demonstration of "Everything Works Together".
5. **Product Editions:** Side-by-side modular comparison cards:
   - *FeeCollect Lite* (Online Fee Collection)
   - *Education ERP* (Lite + Admissions, Academics, Exams, Finance, Faculty, Comm, Admin)
   - *Enterprise Campus Suite* (ERP + Hostel, Transport, HRMS, Payroll, Inventory, Security, Multi-campus, Analytics)
6. **Platform Modules:** Clean grid displaying core functional modules.
7. **Product Showcase:** High-fidelity UI previews showing table clarity, inline forms, and speed.
8. **Why FeeCollect:** Differentiators (Enterprise security, reliability, scalability).
9. **Implementation Journey:** Step-by-step onboarding roadmap.
10. **FAQ:** Interactive accordion addressing buyer objections.
11. **Bottom CTA:** High-impact conversion push.
12. **Footer:** Navigation, legal, multi-campus links, copyright.
